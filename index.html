Interactive Constellation Map

These stars are from the HYG Database. Using right ascension and declination, stereographic projection maps the stars onto this interactive sky map.

Constellation and asterism data comes from Stellarium.

Inspiration came from this GitHub project. My version is interactive, letting users connect stars to find constellations themselves.

Currently only Western constellations are included. Expanding to other cultures is a future upgrade.
